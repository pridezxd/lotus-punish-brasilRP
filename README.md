# Lotus Punish

Site administrativo local para registro de punições.

## Publicação
Este projeto é estático e pode ser publicado no GitHub Pages, Netlify ou Vercel.
O arquivo principal é `index.html`.

## Observação sobre clipes
O botão de download tenta baixar o arquivo diretamente quando o servidor de origem permite CORS.
Quando a origem bloqueia acesso direto (por exemplo, alguns links de terceiros), o navegador abre o link para salvamento manual.
