# BrasilRP Punições — versão simples

Site estático para registrar punições, pesquisar infrações, consultar regras e visualizar o histórico.

## Como usar
Abra `index.html` no navegador.

Os registros ficam salvos no `localStorage` do navegador. Para uso compartilhado por toda a staff, será necessário ligar o site a um banco de dados/backend.
